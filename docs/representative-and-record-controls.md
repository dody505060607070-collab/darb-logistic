# صفحة المندوب والتعديل والحذف

## المندوب بيعمل إيه؟
الصفحة الحالية للمندوب الذي يتابع تكليفات النقل والتسليم، وليست نظام زيارات مبيعات أو تحصيل نقدي مستقل.

1. الإدارة تضيف رقم المندوب وتربطه بملفه، وتكلفه برحلة.
2. يدخل برقم جواله: يرى التكليف، مكان التحميل والتسليم، الموعد والحمولة والمستلم.
3. يسجل وصوله ومراحل التنفيذ، ويرفع المصروف والإيصال أو بلاغ العطل أو التأخير.
4. عند التسليم يسجل المستلم والكمية والصور والتوقيع.
5. طلب الرجوع يذهب للحركة؛ المصروف للمحاسب؛ الأعطال للصيانة وفق التوزيع الحالي.

الإدارة تفتح الصفحة مباشرة دون ربط حسابها بمندوب؛ تختار ملفًا لرؤية رحلاته الحقيقية، أو تختار مثالًا توضيحيًا صريحًا. كل إجراءات المعاينة تمنع الحفظ. المعاينة ليست تسجيل دخول للمندوب نفسه.

زيارات العملاء والتحصيل والمستهدفات ليست منفذة هنا؛ تحتاج دورة مستقلة قبل استخدامها. لا يُعرض لها نجاح أو أرقام مختلقة.

## التعديل والحذف
القلم يفتح نموذج السجل أو ملفه القابل للتعديل. سلة الحذف تفتح تأكيدًا قبل الحذف، وتقتصر على المدير وفق الصلاحيات الموجودة. السجل المرتبط برحلات أو مستندات أخرى قد يمنع حذفه حفاظًا على الارتباطات.

أضيفت الأزرار المتجاورة لقوائم وتفاصيل العملاء والمواقع والعقود والناقلين والمركبات والسائقين والمستندات والتفويضات والفروع والبلاغات وخطط الصيانة والأصناف والإطارات. حسابات الموظفين لديها بالفعل تعديل وحذف مؤكد مع منع حذف الحساب المستخدم.

الفواتير والدفعات والموافقات وأحداث الرحلات ومحاضر العهدة وحركات المخزون ليست سجلات للحذف العام؛ تصحيحها أو إلغاؤها يمر بالإجراءات المخصصة. كذلك عدّادات الملخصات ليست سجلات مستقلة للحذف.
